# Contributing

Thank you for your interest in contributing to this project! Here are the steps to make a safe contribution:

1. Read [README.md](README.md) to understand the project setup and requirements
2. Make a focused change that addresses a single issue or feature
3. Run the documented checks before opening a PR
   - Install dependencies: `npm install`
   - Run tests: `npm test` or `CI=true npm test -- --watchAll=false`
   - Verify no linting issues or formatting problems

We appreciate your contributions and look forward to working with you!
